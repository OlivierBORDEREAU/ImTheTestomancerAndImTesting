# Testomancer – Executive Summary

**Testomancer** is a lightweight, focused skill that turns any AI coding agent into a senior ISTQB-aligned software testing expert.

## Problem

AI agents often generate tests that are:
- Over-engineered or poorly isolated
- At the wrong level (unit vs integration vs E2E)
- Non-compliant with industry standards

## Solution

Testomancer provides structured testing guidance based on three proven frameworks:

| Framework              | Contribution |
|------------------------|--------------|
| **ISTQB**              | Industry-standard terminology and test levels |
| **Testing Pyramid**    | Disciplined distribution (70% Unit, 20% Integration, 10% E2E) |
| **Karpathy Guidelines**| Simplicity, surgical changes, explicit assumptions, verifiable success criteria |

## Key Features

- Real-time codebase analysis and tech stack detection
- Risk-based testing strategy and prioritization
- Level-specific recommendations with modern library suggestions
- Minimal, focused code examples
- Clear justification for every recommendation

## Business Impact

| Metric             | Expected Improvement                     |
|--------------------|------------------------------------------|
| Test Coverage      | Target >80% on critical paths            |
| Execution Time     | Faster via pyramid discipline            |
| Maintenance        | Lower through simpler, surgical tests    |
| Compliance         | Fully ISTQB-aligned outputs              |

## Philosophy

Testomancer is designed to be **tool-agnostic**. It works with OpenCode, Claude Code, Continue.dev, and similar agents. It focuses on reasoning and guidance rather than direct file manipulation.
